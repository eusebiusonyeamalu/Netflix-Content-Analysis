# 🎬 Netflix Content Analysis Dashboard

## 📌 Project Overview

This project analyzes Netflix's content library using Power BI to uncover trends in movies and TV shows, content distribution, production countries, genres, ratings, and release patterns.

The dashboard transforms raw Netflix data into meaningful business insights through data cleaning, visualization, and storytelling.

---

## 🎯 Business Objectives

- Analyze the distribution of Movies and TV Shows
- Identify countries producing the most Netflix content
- Discover the most common genres
- Analyze content ratings
- Examine yearly content additions
- Explore content duration patterns

---

## 🛠 Tools Used

- Microsoft Excel (Data Cleaning)
- Power BI
- DAX
- GitHub

## 📈 Key Insights

- Movies dominate Netflix's catalog.
- Content production is concentrated in a few countries.
- Drama and International Movies are among the most common genres.
- TV Shows have increased significantly in recent years.
- Most content is rated for mature audiences.

---

## 💡 Recommendations

- Expand investment in fast-growing international markets.
- Increase production in high-performing genres.
- Maintain a balanced mix of Movies and TV Shows.
- Continue regional content strategies to improve subscriber engagement.
